#TaskFlow
Es una herramienta web que permite gestionar tareas.

##Descripción 
Es una app desarrollada como proyecto final para demostrar el uso de Git y GitHub del Curso del NODO Tecnológico de Catamarca.

## Funcionalidades
-Permite agregar tareas.
-Eliminar Tareas.
-Con una interfaz sencilla.

## Instalación
Descargar el repositorio
Entrar en la capeta
Abrir index.html en el navegador

## Estructura
> index.html
> styles.css
> script.js
